WS Hub — Versão 1 (primeira versão publicável)

Para publicar pelo GitHub Pages:
1. Crie ou abra o repositório destinado ao WS Hub.
2. Envie os arquivos DE DENTRO desta pasta para a raiz do repositório (não envie apenas o ZIP).
3. Em Settings > Pages, selecione Deploy from a branch, main e /(root).
4. Acesse o endereço exibido pelo GitHub após a publicação.

O que funciona: navegação pelos cinco nós, pulsos de conexão, painéis, observações com linha luminosa, layout mobile, instalação PWA (HTTPS) e acesso offline após a primeira visita.
O que não está conectado: catálogo de cursos, propostas privadas, login do aluno e ferramentas externas. Nenhum acesso falso foi ativado.

Identidade: logo original de Wendell Soares, azul-marinho, dourado e ciano.
A experiência respeita a preferência do sistema por movimento reduzido.
