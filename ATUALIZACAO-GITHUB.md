# Atualização do site Wendell Soares no GitHub

Este ZIP é uma **atualização incremental** do repositório `dellsoares/autoridadedigital`. Ele contém somente arquivos alterados e três novas ilustrações. Não é necessário apagar nem substituir o restante do repositório.

## Como publicar

1. Baixe e descompacte este ZIP no computador.
2. Abra o repositório: https://github.com/dellsoares/autoridadedigital
3. Clique em **Add file → Upload files**.
4. Arraste para a área de upload todos os arquivos e pastas que estão dentro da pasta descompactada. Mantenha a estrutura de pastas.
5. O GitHub identificará os arquivos existentes que precisam ser atualizados e as três novas imagens.
6. Use a mensagem de commit: `Integra blog, navegação e identidade visual`.
7. Clique em **Commit changes** e aguarde o GitHub Pages concluir a publicação.

**Não envie o ZIP fechado para o repositório e não apague os arquivos atuais.** Descompacte e envie o conteúdo. Os arquivos que não aparecem neste pacote permanecem como estão.

## O que esta atualização faz

- Liga os links Blog do cabeçalho, menu mobile, rodapé e chamada da home a `/blog/`.
- Remove os destinos antigos de outro domínio do conteúdo do site.
- Mantém as oito capas originais e os links das oito categorias.
- Remove os selos `CAPA / 01`, `CAPA / 02` etc.
- Remove o bloco final repetido “Próxima órbita”.
- Adiciona a seção **Toró de ideias**, com três capas vetoriais quadradas 1:1.
- Padroniza cabeçalho e rodapé das páginas internas com a estrutura usada na home.
- Corrige os links de navegação interna para apontarem às seções corretas da home (por exemplo, `/#sobre`) em vez de tentar encontrar essas âncoras dentro do blog.
- Atualiza o cabeçalho do FAQ e mantém seu conteúdo, busca e perguntas.
- Preserva os títulos SEO, meta descriptions, canonicals e dados estruturados existentes.
